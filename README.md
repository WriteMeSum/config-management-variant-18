# Граф зависимостей Maven: вариант 18

Практическая работа по конфигурационному управлению на Python 3.9+.
Приложение читает настройки CSV, самостоятельно получает Maven POM,
строит граф итеративным DFS, вычисляет порядок загрузки и создает
визуализацию D2/SVG. Поддерживается файловый тестовый репозиторий.

## Быстрый запуск

Python-зависимостей для работы приложения нет. Для изображения нужен
[D2 CLI](https://d2lang.com/tour/install), проверенная версия D2 0.9.0.
На macOS: `brew install d2`. Maven нужен только для эталонного сравнения.

```sh
git clone https://github.com/WriteMeSum/config-management-variant-18.git
cd config-management-variant-18
./run.sh examples/junit.csv
```

Создаются `output/dependencies.d2` и `output/dependencies.svg`.
Изображение открывается в Firefox на macOS, на других платформах в браузере
по умолчанию. Режим `--no-open` подходит для сервера и автоматизации.
Каталог `output/` исключен из Git: изображения являются артефактами запуска.

```sh
./run.sh examples/diamond.csv --output output/diamond --no-open
./run.sh --help
make build
make test
make demo
```

`make build` проверяет компиляцию исходников Python; отдельная компоновка
не требуется. `make test` запускает автономные unittest-тесты без сети,
Maven и D2. `make demo` создает визуализации трех настоящих пакетов.

## Настройки CSV

Все пять ключей обязательны, порядок строк произволен. Формат UTF-8,
разделитель запятая, первая строка строго `key,value`.

```csv
key,value
package,junit:junit
repository,https://repo.maven.apache.org/maven2
test_mode,false
version,4.13.2
ascii_tree,true
```

| Ключ | Назначение и допустимые значения |
| --- | --- |
| package | Maven `groupId:artifactId`, в тестовом режиме большие буквы A-Z |
| repository | HTTP(S) URL Maven или путь к JSON относительно CSV-файла |
| test_mode | `true` для файла, `false` для HTTP(S) репозитория |
| version | Фиксированная версия, например `4.13.2`; диапазоны запрещены |
| ascii_tree | `true` включает ASCII-дерево; `false` отключает |

Регистр true/false несущественен. Пробелы по краям значений удаляются.
Дубликаты, неизвестные ключи, пропуски, пустые значения и лишние поля
запрещены. Ошибки приложения направляются в stderr с кодом 1, ошибки
аргументов CLI с кодом 2; успех имеет код 0.

```sh
python3 scripts/demo_errors.py
```

Команда демонстрирует ошибки каждого параметра: неверное имя, URL,
булевы флаги и диапазон версий. Записанный вывод: [ошибки](docs/errors.md).

## Этапы и история

Каждый этап реализован отдельным коммитом Conventional/Scoped Commits.
Теги `stage-1` ... `stage-5` позволяют просмотреть состояние каждого этапа.
В финальной версии временные выводы доступны только через `--stage`.
Обычный запуск соответствует этапу 5.

| Этап | Флаг | Результат |
| --- | --- | --- |
| 1 | `--stage 1` | Пять параметров в виде ключ=значение |
| 2 | `--stage 2` | Все прямые зависимости выбранной версии |
| 3 | `--stage 3` | Транзитивные ребра графа и обнаруженные циклы |
| 4 | `--stage 4` | Порядок загрузки; ошибка при цикле |
| 5 | `--stage 5` | D2, изображение SVG и запрошенное ASCII-дерево |

```sh
./run.sh examples/junit.csv --stage 1
./run.sh examples/junit.csv --stage 2
./run.sh examples/diamond.csv --stage 3
./run.sh examples/diamond.csv --stage 4
./run.sh examples/cycle.csv --stage 5 --output output/cycle
```

Дополнительные операционные флаги: `--output PATH` задает основу имен
выходных файлов (по умолчанию `output/dependencies`); `--no-open`
отключает открытие браузера. `--help` описывает аргументы.
Для shell-скрипта можно задать `PYTHON=/path/to/python3`.
Для Makefile: `make test PYTHON=/path/to/python3`.

## Тестовые репозитории и DFS

JSON описывает список смежности: `{"A":["B"],"B":[]}`.
Все упомянутые узлы объявляются явно, листья имеют пустые списки.
Имена состоят из одной или нескольких больших латинских букв.
Повторные JSON-ключи запрещены, повторные ребра объединяются.
JSON не моделирует версии; поле version проверяется, но граф не меняет.

| Конфигурация | Случай | Порядок этапа 4 |
| --- | --- | --- |
| `examples/chain.csv` | Цепочка A → B → C | C, B, A |
| `examples/diamond.csv` | Ромб с общей зависимостью D | D, B, C, A |
| `examples/isolated.csv` | Отдельный узел A | A |
| `examples/cycle.csv` | Цикл A → B → C → A | Ошибка |
| `examples/self-cycle.csv` | Петля A → A | Ошибка |

Обход использует стек итераторов и множество активных узлов без рекурсии.
Циклическое ребро сохраняется, дальнейший обход по нему прекращается.
Общий узел не вызывает повторной загрузки того же состояния; состояние
учитывает исключения на пути. В итоговом графе объединяются разрешенные
ребра разных путей. ASCII-дерево отмечает `[cycle]` и `[shared]`,
не разворачивая бесконечные и повторные поддеревья.

Порядок загрузки вычисляется итеративным DFS postorder. Каждая зависимость
идет раньше зависимого, корень последний. При цикле топологический порядок
невозможен. Это логический порядок, а не хронология HTTP-запросов Maven.

## Три реальных пакета и сравнение

```sh
./run.sh examples/junit.csv --output output/junit
./run.sh examples/commons-text.csv --output output/commons-text
./run.sh examples/commons-io.csv --output output/commons-io
python3 scripts/compare_maven.py
```

Для JUnit 4.13.2, Commons Text 1.10.0 и Commons IO 2.11.0 проверены
D2/SVG и ASCII-деревья. Узлы и ребра совпали с Maven `dependency:tree`
при `scope=runtime`. Сравнение и объяснение отличий порядка:
[эталон Maven](docs/comparison.md), [визуализации](docs/visualization.md).
Maven вызывается исключительно отдельным скриптом сравнения.

## Сбор данных и границы поддержки

Приложение использует только стандартную библиотеку Python: urllib, XML,
CSV и JSON. Менеджеры пакетов и готовые библиотеки получения зависимостей
не используются. D2 вызывается только после построения графа для рендера.

На этапе 2 выводятся прямые зависимости всех областей видимости.
Для графа этапов 3–5 используются зависимости compile/runtime.

Поддержаны namespace XML, свойства `${...}`, parent POM, наследование
зависимостей, dependencyManagement, импорты BOM, compile/runtime, optional
и exclusions с wildcard. Загрузчик имеет кэш POM в памяти, таймаут HTTP
20 секунд, лимит POM 4 МиБ и защиту от циклов parent/BOM.
XML DTD и пользовательские сущности запрещены.
Рендер D2 ограничен 60 секундами.

Граф показывает объявленные версии и не выполняет Maven nearest-wins
медиацию конфликтов. Не поддержаны диапазоны/динамические версии,
разрешение timestamped SNAPSHOT, профили, relocation и дополнительные
репозитории из POM. Тип/классификатор не создают отдельные узлы: анализ
ведется на уровне координат groupId:artifactId:version. Сложное
переопределение свойств унаследованных зависимостей в child поддержано
не полностью. Подробности и влияние на сравнение описаны в отчете.

## Проверка оформления

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
make build test lint PYTHON=.venv/bin/python
```

Ruff проверяет PEP8, имена, сложность и магические числа в сравнениях;
`scripts/check_rules.py` проверяет лимиты методички: 80 символов строки
Python, 120 остальных строк, 40 строк функции, 7 аргументов,
1000 строк файла, цикломатическая сложность до 10, docstring и отсутствие
служебных/бинарных файлов. Проверки выполняются также в GitHub Actions.

Структура: `src/mavengraph/` — исходники, `tests/` — тесты,
`examples/` — CSV/JSON, `docs/` — результаты и руководство,
`scripts/` — проверка правил, сравнение и демонстрация ошибок.
